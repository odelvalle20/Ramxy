# V5: cambios y flujo

La V5 transforma el laboratorio en una demo local con panel web y separación explícita entre originales, cifrados y recuperados.

## Nuevas capacidades

- Panel web en `/`.
- Token `LAB_ADMIN_TOKEN` para listar agentes y crear órdenes.
- Registro de agentes y polling real conectado a la cola.
- Simulación previa que solo enumera archivos permitidos.
- Soporte para varias extensiones comunes.
- Cifrado Fernet de copias: los originales nunca se eliminan.
- Recuperación en una carpeta separada.
- Hash SHA-256 en el manifiesto para verificar integridad.
- Historial de órdenes persistente.

## Flujo V5

```text
agente registra -> panel autentica -> orden dirigida a un agente
-> agente hace polling -> operación local -> resultado -> historial
```

El ZIP de referencia tenía panel y API, pero sus órdenes no llegaban al agente porque no implementaba `/api/poll` ni `/api/resultado`. Esta repo V5 completa ese circuito y añade pruebas del flujo extremo a extremo.

## Carpetas

```text
laboratorio/
├── originales/   archivos ficticios conservados
├── cifrados/     copias Fernet y manifest.json
├── recuperados/  copias descifradas verificadas
└── claves/       clave local, nunca versionada
```

La ruta base puede cambiarse con `LAB_BASE`. Usa siempre una carpeta temporal o de laboratorio.
