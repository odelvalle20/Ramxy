# Contribuir

Gracias por ayudar a mejorar el laboratorio. Las contribuciones deben mantener su alcance educativo y defensivo.

## Antes de empezar

- Trabaja únicamente con datos ficticios y equipos autorizados.
- No añadas propagación, persistencia, evasión, robo de credenciales o ejecución arbitraria.
- No incluyas claves, archivos `.enc`, datos personales ni capturas sensibles.

## Flujo de trabajo

1. Abre una issue describiendo el problema o la mejora.
2. Crea una rama pequeña y enfocada.
3. Añade o actualiza pruebas cuando cambie el comportamiento.
4. Ejecuta `py -m pytest -q`.
5. Documenta cualquier cambio de instalación o de seguridad.
6. Abre un pull request explicando el objetivo y las pruebas ejecutadas.

## Áreas especialmente útiles

- Detecciones con Sysmon, Windows Event Logs o SIEM.
- Guías reproducibles para VirtualBox y VMware.
- Mejoras de telemetría y manejo de errores.
- Traducciones y diagramas de arquitectura.
